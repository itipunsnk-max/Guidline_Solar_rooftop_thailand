# 9.2 การต่อลงดินและการเลือกสาย AC สำหรับ String Inverter

เอกสารนี้สรุปแนวทางสำหรับ Inverter ยี่ห้อ **Sungrow** และ **Huawei** เพื่อใช้ตรวจแบบและประมาณ BOQ เบื้องต้น โดยอ้างอิงคู่มือผู้ผลิตและ IEC 60364

> **ข้อสรุปสั้น:** ต้องแยกให้ชัดว่า PE ต่ออยู่ที่ใด ได้แก่ **PE ในชุดสาย AC** หรือ **External / Chassis PE ที่ตัวถัง Inverter** แล้วจึงเลือกจำนวนและขนาดสายตามคู่มือของ **รุ่นที่ติดตั้งจริง** ห้ามกำหนดเหมารวมว่า Inverter ทุกเครื่องต้องมี PE สองเส้นและทุกเส้นต้องมีขนาด `S/2`

เอกสารต้นฉบับที่ใช้ประกอบการจัดทำหัวข้อนี้: [9.2.Grounding_Huawei & Sungrow.pdf](<9.2.Grounding_Huawei & Sungrow.pdf>)

## 9.2.1 ภาพรวมระบบต่อลงดินของ Solar Rooftop

![รูปที่ 9.2.1 ส่วนประกอบการต่อลงดินระบบ Solar Rooftop](<9.2.1.มาตรฐานการ Bondding และ External Grounding.jpeg>)

**รูปที่ 9.2.1** แสดงภาพรวมการรวมสายดินของโครงสร้างแผง, SPD, Inverter และตู้ไฟเข้ากับ Ground Bar และระบบหลักดินของอาคาร

หลักสำคัญจากรูปคือ:

- โครงสร้างแผง PV, SPD, ตัวถัง Inverter และตู้ไฟต้องอยู่ในระบบ **Protective Earthing / Equipotential Bonding** เดียวกัน
- หากเพิ่มหลักดินบริเวณตู้ Solar ต้องเชื่อมประสานกับระบบหลักดินเดิมตามแบบที่ได้รับอนุมัติ ไม่ควรทำเป็นระบบดินแยกอิสระ
- สายดินแต่ละช่วงอาจมีต้นทางและระยะเดินสายต่างกัน จึงต้องถอดปริมาณตามเส้นทางจริง

หลักการนี้สอดคล้องกับ IEC 60364-5-54 ซึ่งครอบคลุม earthing arrangements, protective conductors และ protective bonding conductors[^1]

## 9.2.2 การต่อ Ground ของ String Inverter

![รูปที่ 9.2.2 การต่อ Ground ของ String Inverter](<9.2.2.GPT Gen Grounding.jpg>)

**รูปที่ 9.2.2** ใช้อธิบายเส้นทางการเดินสายจาก Inverter ไปยัง ACDB/SMDB และ Main Earth Bar โดยแยกจุดต่อออกเป็น:

| ชื่อสาย | จุดเริ่มต้น | หน้าที่ |
|---|---|---|
| `PE (AC)` | PE terminal ในส่วน AC ของ Inverter | Protective conductor ที่เดินร่วมกับวงจร AC ตาม wiring scheme ของรุ่นนั้น |
| `External / Chassis PE` | External grounding stud บนตัวถัง Inverter | เชื่อมตัวถังหรือ enclosure เข้ากับระบบ PE / Main Earth Bar |
| `N` | Neutral terminal | ใช้เฉพาะรุ่นและระบบไฟฟ้าที่กำหนดให้มี Neutral |

> **ข้อควรระวังในการใช้รูปที่ 9.2.2:** ข้อความ `PE = S/2` และ `External PE = PE ในสาย AC` ในรูปเป็นตัวอย่างสำหรับบางรุ่นของ Sungrow ไม่ใช่ข้อกำหนดกลางสำหรับ Inverter ทุกยี่ห้อ ต้องตรวจคู่มือรุ่นจริงก่อนนำไปออกแบบหรือทำ BOQ

## หลักการเลือกจำนวนและขนาดสาย

### 1. ตรวจรุ่น Inverter และระบบไฟฟ้า

เริ่มจากข้อมูลต่อไปนี้:

- รุ่นและ revision ของคู่มือ
- แรงดัน AC และรูปแบบระบบ เช่น `3/N/PE` หรือ `3W+PE`
- ระบบสายดินของโครงการ เช่น TN-S, TN-C-S หรือ TT
- รูปแบบสาย AC ที่เลือกใช้ เช่น single-core หรือ multicore

ไม่ใช่ String Inverter 3 เฟสทุกตัวจะมีสาย Neutral ตัวอย่างเช่น Huawei SUN2000-50KTL-M3 ระบุ `400/480 Vac, 3W+(N)+PE` จึงต้องพิจารณา N ตามระบบที่ใช้งาน[^8] ขณะที่ Sungrow SG350HX และ Huawei SUN2000-330KTL-H1 เป็นระบบ `800 V, 3W/3+PE` และไม่มี N[^7][^11]

### 2. ออกแบบสาย Phase ก่อน

กำหนดขนาดสาย Phase จาก:

- กระแสใช้งานและพิกัดอุปกรณ์ป้องกัน
- วิธีติดตั้งและอุณหภูมิแวดล้อม
- การรวมกลุ่มสายและค่า derating
- แรงดันตก
- กระแสลัดวงจร
- ขนาด terminal และ lug ที่ Inverter รองรับ

IEC 60364-5-52 ครอบคลุมการเลือกและติดตั้ง wiring systems รวมถึงข้อพิจารณาเรื่องแรงดันตก[^2]

### 3. กำหนด PE จากคู่มือผู้ผลิตและมาตรฐาน

ให้กำหนด:

- `S` = พื้นที่หน้าตัดของสาย Phase
- `Sp` = พื้นที่หน้าตัดของสาย PE

กรณีสาย Phase และ PE เป็นวัสดุชนิดเดียวกัน วิธีตารางตาม IEC 60364-5-54 สรุปได้ดังนี้:[^1]

| ขนาดสาย Phase `S` | ขนาดสาย PE `Sp` |
|---:|---:|
| `S ≤ 16 mm²` | `Sp = S` |
| `16 < S ≤ 35 mm²` | `Sp = 16 mm²` |
| `S > 35 mm²` | `Sp = S/2` |

หากค่าที่คำนวณได้ไม่ตรงกับขนาดสายมาตรฐาน ให้เลือก **ขนาดมาตรฐานลำดับถัดไปที่มากกว่า** และตรวจว่า terminal/lug รองรับ ตัวอย่าง `95/2 = 47.5 mm²` จึงเลือกอย่างน้อย `50 mm²`

> คู่มือผู้ผลิตอาจกำหนดเงื่อนไขเฉพาะรุ่นที่ต่างจากตารางทั่วไป การออกแบบขั้นสุดท้ายต้องเป็นไปตามทั้งคู่มือรุ่นจริง มาตรฐานท้องถิ่น และข้อกำหนดของโครงการ

### 4. รวมสาย PE เข้าสู่ระบบเดียวกัน

สาย PE ทุกเส้นต้องเชื่อมเข้าสู่ common PE / Main Earthing System ตามแบบที่ได้รับอนุมัติ ไม่ควรสร้างระบบหลักดินแยกเฉพาะ Inverter โดยไม่มี bonding กลับสู่ระบบหลัก[^1]

## ข้อกำหนดตามรุ่นที่ตรวจสอบ

### Sungrow

| รุ่น | AC configuration | แนวทาง PE สำหรับ BOQ เบื้องต้น |
|---|---|---|
| **SG50CX-P2** | `3/N/PE` ที่ 380/400 V | คู่มือกำหนด PE ตาม `S/2` สำหรับรุ่นนี้ และ External grounding cable มีขนาดเท่ากับ PE ในชุดสาย AC[^3] |
| **SG125CX-P2** | 3 เฟส; ตรวจ N ตาม configuration | แยก AC PE และ External PE ใน BOQ แล้วกำหนดขนาดตามคู่มือรุ่นจริง[^4] |
| **SG150CX** | 3 เฟส; ตรวจ N ตาม configuration | คู่มือระบุ PE `S/2` เมื่อ Phase และ PE เป็นวัสดุเดียวกัน[^5] |
| **SG350HX** | `3/PE, 800 V` | ไม่มี N; กำหนด PE ตามคู่มือและ cable arrangement ของรุ่นนี้[^6][^7] |

สำหรับ SG50CX-P2, SG125CX-P2 และ SG150CX การเผื่อ `PE (AC)` กับ `External PE` แยกรายการใน BOQ ช่วยลดความเสี่ยงสายตกหล่น แต่ต้องยืนยันจำนวนจุดต่อและขนาดสายจากคู่มือ revision ที่ใช้กับเครื่องจริง

### Huawei

Huawei ต้องพิจารณาตาม Series และ wiring scheme มากกว่าการใช้กฎเดียวทุกเครื่อง

| รุ่น | AC configuration | แนวทาง PE สำหรับ BOQ เบื้องต้น |
|---|---|---|
| **SUN2000-50KTL-M3** | `400/480 Vac, 3W+(N)+PE` | ตรวจการใช้ N และตำแหน่ง PE ตามคู่มือรุ่นจริง ห้ามนำขนาด External PE ของ Sungrow มาใช้โดยอัตโนมัติ[^8][^9] |
| **SUN2000-100/110/115KTL-M2** | 3 เฟส; N ตาม wiring scheme | เลือก enclosure PE หรือ PE ใน AC compartment ตาม arrangement ที่คู่มืออนุญาต และตรวจขนาดจากตาราง PE ของคู่มือ[^10] |
| **SUN2000-150K-MG0** | รองรับหลาย AC/PE configuration | คู่มือระบุให้เลือกจุด PE บน enclosure หรือใน maintenance compartment เมื่อขนาดสายเป็นไปตามข้อกำหนด ไม่จำเป็นต้องต่อสองจุดพร้อมกันทุกกรณี[^12] |
| **SUN2000-330KTL-H1** | `800 V, 3W+PE` | ไม่มี N; ใช้ 3 Phase + PE และตรวจจุดต่อ/ขนาด PE จากคู่มือของรุ่น[^11] |

ดังนั้น Huawei ไม่ควรถูกกำหนดด้วย General Note ว่า `External PE = PE ในสาย AC` หรือ `ต้องมี PE สองเส้นเสมอ` เว้นแต่คู่มือรุ่นนั้นหรือข้อกำหนดโครงการระบุไว้

## รูปแบบที่แนะนำใน Drawing

ให้ใช้ notation กลางดังนี้:

```text
L1 / L2 / L3 / (N) / PE
```

โดยเพิ่มหมายเหตุ:

> `(N): Optional; subject to the inverter model, AC voltage, grid configuration, and approved design.`

สำหรับสาย PE แนะนำข้อความดังนี้:

> `PE conductor shall be sized in accordance with the applicable inverter manufacturer's manual, IEC/local standard, and approved project design.`

> `External / Chassis PE shall be connected from the designated grounding point on the inverter enclosure to the common PE / Main Earthing System. Do not create an isolated earthing system for the inverter.`

ข้อความนี้ชัดเจนกว่าการระบุเพียง `PE = S/2` เพราะครอบคลุมความแตกต่างของแต่ละรุ่น

## แนวทางถอด BOQ

ให้ถอดสายแต่ละเส้นแยกกันตามระยะเดินจริง:

```text
L1             = ระยะ Inverter → ACDB/SMDB
L2             = ระยะ Inverter → ACDB/SMDB
L3             = ระยะ Inverter → ACDB/SMDB
N              = คิดเฉพาะเมื่อรุ่นและระบบกำหนดให้มี
PE (AC)        = คิดตาม wiring scheme และ route ของ AC feeder
PE (External)  = ระยะ Ground Stud → Local PE Bar / Main Earth Bar ตามแบบ
```

External PE อาจสั้นกว่าระยะ AC feeder หากต่อเข้ากับ Local PE Bar ใกล้เครื่องและ Local PE Bar นั้น bond กลับ Main Earth Bar อย่างถูกต้อง จึงควรวัด route จริง ไม่ควรคูณระยะ Inverter–SMDB โดยอัตโนมัติ

## Checklist ก่อนออกแบบและสั่งซื้อ

- [ ] ยืนยันยี่ห้อ รุ่น และ revision ของคู่มือ
- [ ] ยืนยันแรงดัน AC และ grid configuration
- [ ] ยืนยันว่าต้องมี Neutral หรือไม่
- [ ] ยืนยันจุดต่อ PE ที่ผู้ผลิตกำหนด
- [ ] คำนวณสาย Phase ก่อนกำหนดขนาด PE
- [ ] ตรวจวัสดุสาย, terminal, lug และค่า torque
- [ ] ตรวจว่า PE ทุกเส้น bond เข้าระบบ Main Earthing System เดียวกัน
- [ ] วัดระยะ AC PE และ External PE ตาม route จริง
- [ ] แยก Design Assumption ออกจาก Final Design ใน BOQ
