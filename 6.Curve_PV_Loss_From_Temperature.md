# Jinko 725 W Module Curves and Temperature/Irradiance Summary

This package is prepared for GitHub and is based on the uploaded datasheet:

- **Module**: JinkoSolar JKM700-725N-66HL5-BDV-Z2C2-OC
- **Selected power class**: **725 W**
- **Requested irradiance cases**: **500 W/m²** and **1000 W/m²**
- **Requested cell-temperature range**: **10°C to 90°C**

## 1) Datasheet inputs used

The calculations in this package use the following values:

| Parameter | Value | Note |
|---|---:|---|
| Pmax at STC | 725 W | Datasheet |
| Imp at STC | 17.69 A | User-provided value |
| Vmp at STC | 40.98 V | Derived as `725 / 17.69` |
| Isc at STC | 18.74 A | Datasheet |
| Voc at STC | 49.20 V | Datasheet |
| Temperature coefficient of Isc | +0.045 %/°C | Datasheet |
| Temperature coefficient of Voc | -0.25 %/°C | Datasheet |
| Temperature coefficient of Pmax | -0.29 %/°C | Datasheet |

> **Important note**
>
> This package uses a **simplified engineering reconstruction** of the I-V and P-V curves from the datasheet values and temperature coefficients.
> It is suitable for trend comparison, engineering discussion, and GitHub documentation.
> It is **not** a manufacturer-certified simulation model.

## 2) Equations used

### Current scaling

```text
Isc(G,T) = Isc_ref × (G / 1000) × [1 + α_Isc × (T - 25)]
Imp(G,T) = Imp_ref × (G / 1000) × [1 + α_Isc × (T - 25)]
```

### Power scaling

```text
Pmp(G,T) = Pmp_ref × (G / 1000) × [1 + γ_Pmp × (T - 25)]
```

### Voltage scaling

```text
Voc(G,T) = Voc_ref × [1 + β_Voc × (T - 25)] + C(T) × ln(G / 1000)
Vmp(G,T) = Pmp(G,T) / Imp(G,T)
```

### Reconstructed I-V curve

```text
I(V) = Isc × [1 - (V / Voc)^a]
```

where the exponent `a` is fitted so that the curve passes through `(Vmp, Imp)`.

## 5) Quick interpretation

### When temperature increases
- **Voltage decreases clearly** (`Voc` and `Vmp` drop with temperature)
- **Current increases slightly** (`Isc` and `Imp` rise only a little)
- **Power decreases overall** because the voltage drop dominates

### When irradiance decreases from 1000 to 500 W/m²
- **Current is reduced strongly** (roughly proportional to irradiance)
- **Voltage drops moderately**
- **Power falls by about half**, then shifts further with temperature
