**ขอบเขตของรอบนี้:** อ่านเอกสาร, จัดทำ Input Register, Design Basis Register, Standard Register, Missing Information Register และ Assumption Register เท่านั้น

## 1. Executive Summary

ยังไม่พบไฟล์ `Solar_Rooftop_Project_Data_Form.xlsx` หรือเอกสารเฉพาะโครงการ เช่น แบบหลังคา, SLD เดิม, load profile, utility requirement และใบเสนอราคา จึงยังไม่สามารถยืนยันข้อมูลพื้นฐานของระบบเดิม ขนาดระบบ จุดเชื่อมต่อ หรือราคาต้นทุนได้ อย่างไรก็ตาม ได้รับและตรวจเอกสารตัวอย่างจากผู้ผลิตแล้ว 3 ชุด ได้แก่ Bangkok Cable Electrical Design & Installation Guide, Panasonic White Conduit Catalogue และ KJL Cable Ladder Catalogue พร้อมจัดทำ Cable Containment Data Register สำหรับกรอกข้อมูลต่อ

ผลการตรวจความพร้อมยังเป็น **NO-GO สำหรับ PHASE 1-5** เนื่องจากเอกสารผู้ผลิตที่ได้รับเป็นข้อมูลตัวอย่าง ไม่ใช่ Approved Project Input และยังขาดข้อมูล Critical ที่กระทบทั้งความปลอดภัย ความถูกต้องของขนาดระบบ การตรวจ string voltage/current การเลือกสายและอุปกรณ์ป้องกัน การประเมินโครงสร้าง และการขออนุญาต รอบนี้จึงบันทึกเฉพาะข้อมูลสาย AC, ท่อ IMC และ Cable Ladder; ข้อมูลสาย DC ยังไม่ถูกนำลงตามคำสั่งผู้ใช้

รอบถัดไปควรเริ่มจากส่งไฟล์ข้อมูลหลักและเอกสารประกอบตาม Missing Information Register โดยคงชื่อไฟล์และวันที่เอกสารให้ตรวจย้อนกลับได้ เมื่อได้รับข้อมูลแล้วจึงทำ Input Register ระดับไฟล์/แท็บ/ช่วงเซลล์ และประเมินว่าอนุญาตให้เดินหน้าได้ถึงระดับ Preliminary Design หรือไม่

## 2. วิธีใช้คู่มือนี้

1. วางไฟล์ทั้งหมดในโฟลเดอร์โครงการเดียวกัน โดยไม่เปลี่ยนชื่อไฟล์ต้นฉบับหลังเริ่มตรวจ
2. เพิ่ม revision/date ในชื่อไฟล์หรือเอกสาร และระบุผู้ส่งหรือเจ้าของข้อมูล
3. กรอก `Solar_Rooftop_Project_Data_Form.xlsx` ให้ครบเท่าที่ทราบ โดยไม่เดาค่า
4. ใช้คำว่า `UNKNOWN`, `TBC` หรือ `N/A` แทนช่องว่างที่มีความหมาย และอธิบายเหตุผล
5. ให้เจ้าของข้อมูลตอบ Missing Information Register ตาม Priority และ Go/No-Go
6. ให้ Lead Engineer ปิด Assumption Register และอนุมัติ Design Basis ก่อนเริ่มคำนวณ
7. เก็บไฟล์ที่ใช้คำนวณทุกฉบับไว้เป็นชุด frozen input พร้อม checksum หรือ revision log

## 9. PHASE 0 Workflow สำหรับรอบถัดไป

### Gate 0A - Intake

- บันทึกชื่อไฟล์, ขนาดไฟล์, modified date, revision, ผู้ส่ง และวัตถุประสงค์
- ตรวจไฟล์ซ้ำ, ไฟล์เสีย, password protection, missing pages และ superseded revisions
- สำหรับ workbook ให้บันทึกทุก sheet, used range, หน่วย, formula/value, blank fields และ data validation
- สำหรับ PDF/drawing ให้บันทึก title block, drawing number, revision, scale และจำนวนหน้า
- สำหรับรูป ให้บันทึกตำแหน่ง ทิศทาง วันที่ และสิ่งที่ภาพพิสูจน์ได้/พิสูจน์ไม่ได้

### Gate 0B - Source Classification

- แยกข้อมูลจาก datasheet, field survey, owner statement, utility requirement, calculation และ assumption
- หากค่าซ้ำกันหลายแหล่ง ให้สร้าง Conflict Register แทนการเลือกค่าหนึ่งเอง
- หากเอกสารไม่มีวันที่หรือ revision ให้จัดเป็น `Provided - Unverified`
- ข้อมูลจากรูปภาพห้ามใช้เป็นมิติจริง เว้นแต่มีสเกลหรือการวัดที่ตรวจสอบได้

### Gate 0C - Readiness Decision

ให้เลือกสถานะสูงสุดที่ข้อมูลรองรับ:

| Readiness Level | Allowed Work | Prohibited Conclusion |
|---|---|---|
| R0 - Intake only | Register และคำถาม | ห้ามคำนวณหรือเสนอขนาดระบบ |
| R1 - Preliminary screening | ทางเลือกเชิงแนวคิดพร้อม assumption ชัดเจน | ห้ามสรุป compliance หรือ IFC |
| R2 - Preliminary design | Option comparison, preliminary string/layout | ห้ามปิด cable/protection/structure |
| R3 - Detailed calculation ready | Calculation Book และ coordinated schedules | ยังต้อง Engineer Review ก่อน issue |
| R4 - Engineer-reviewed | ชุดพร้อมยื่น/ก่อสร้างตามขอบเขตที่ลงนาม | AI ไม่ใช่ผู้ลงนามหรือผู้รับรองแบบ |

### 16.5 Physical Fill Calculation Sheet

**Conduit formulas**

- A_cable_i = pi x OD_i^2 / 4
- A_used = sum(A_cable_i x quantity_i)
- A_internal = pi x ID_actual^2 / 4
- Allowed usable area = A_internal x adopted fill limit
- Fill_percent = 100 x A_used / A_internal
- N_physical_max = floor(Allowed usable area / A_one_cable)

**Tray/Ladder formulas**

- Method = area-fill OR width-occupancy, selected by approved standard and tray type
- Usable area/width = actual internal dimension less required margin/segregation
- Calculated occupancy = sum(actual cable OD/area based on the adopted method)
- N_physical_max is a physical-space result only; it is not an ampacity approval

สำหรับ AC 1-core ต้องบันทึก trefoil/flat, phase order, spacing, number of complete circuits, parallel-run symmetry และผลต่อ X/ampacity ห้ามนับ phase conductor แยกจากวงจรครบชุด

## 23. Cable/Containment/Voltage-Drop QA Checklist

- [ ] ทุก Circuit ID ตรงกันระหว่าง SLD, current map, route, cable, containment, VD และ BOQ
- [ ] OD มาจากรุ่นจริงและ core count/size ตรงกัน
- [ ] Conduit ID หรือ tray usable dimension มาจากรุ่นจริง ไม่ใช้ nominal size แทน
- [ ] Physical fill และ thermal derating ผ่านแยกกัน
- [ ] AC 1-core ถูกจัดเป็นวงจรครบชุดและบันทึก trefoil/flat/spacing
- [ ] DC homerun ใช้กระแสตามจำนวน parallel strings ของ segment จริง
- [ ] R(T) แสดงวิธีปรับอุณหภูมิและ source; X สอดคล้องกับ arrangement
- [ ] VD V/m และ percent/m แสดง I, V, PF, R/X, temperature และ arrangement
- [ ] Total VD รวมเฉพาะ segments ที่มีเส้นทางกระแสเดียวกันและไม่มี double count
- [ ] Project VD limits มี source/approval; ไม่มีการอ้าง 2-5% เป็นกฎสากล
- [ ] เปรียบเทียบอย่างน้อย 2 ขนาดเมื่อมี trade-off และราคาเป็น source/date จริง
- [ ] BOQ trace กลับ route/circuit พร้อม fittings, supports, glands, lugs, connectors, earthing และ signage
- [ ] HP-CV-01 ถึง HP-CV-10 ปิดก่อน issue for construction
