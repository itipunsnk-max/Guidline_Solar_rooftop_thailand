# Project: Solar Rooftop String & MPPT Design Assistant

Act as:

- Senior Solar PV System Design Engineer
- Senior Electrical Engineer
- PVsyst System Designer
- Sungrow C&I Inverter Specialist
- Excel Solution Architect
- Python and VBA Developer
- Quality Assurance Engineer

Create a complete Excel-based engineering tool named:

**Solar Rooftop String & MPPT Design Assistant**

The tool will be used to perform preliminary and detailed electrical design for commercial and industrial solar rooftop systems.

The workflow should be similar in concept to Huawei SmartDesign or Sungrow iSolarDesign, but the first version must be built in Microsoft Excel and must produce structured data that can be transferred into PVsyst.

The tool must not claim to replace PVsyst, manufacturer design software, certified engineering calculations, or final construction drawings.

---

# 1. Target User

The target user is an electrical engineer who:

- Has an aerial roof image or AutoCAD PV layout
- Already knows the approximate location and quantity of PV modules
- Needs assistance grouping modules into strings
- Needs assistance assigning strings to inverter MPPTs
- Needs electrical validation
- Needs DC cable calculations
- Needs a clean data package for PVsyst
- Uses Microsoft Excel
- May later convert the tool into a Python Streamlit web application

The user should be able to operate the workbook without editing formulas manually.

# 6. String Design Engine

Create a worksheet named `String_Designer`.

The system must calculate allowable modules per string.

## 6.1 Cold Voc Calculation

Use:

Voc_cold =
Voc_STC × [1 + ABS(Beta_Voc) × (25 - Tmin)]

Support temperature coefficient entered as either:

- %/°C
- decimal/°C

Prevent unit conversion errors.

Calculate:

Nmax_absolute =
FLOOR(Max_Inverter_DC_Voltage / Voc_cold)

Calculate:

Nmax_design =
FLOOR(
Max_Inverter_DC_Voltage × Voltage_Safety_Factor
/ Voc_cold
)

The voltage safety factor must be editable and clearly documented.

Never silently use a safety factor.

---

## 6.2 Hot Vmp Calculation

Use:

Vmp_hot =
Vmp_STC × [1 + Beta_Vmp × (Tcell_max - 25)]

When Beta_Vmp is unavailable:

- Do not invent it.
- Allow the user to use a documented engineering assumption.
- Clearly flag the result as assumption-based.

Calculate:

Nmin_MPPT =
CEILING(MPPT_Min_Voltage / Vmp_hot)

Also verify:

- String Vmp at hot condition
- String Vmp at STC
- String Vmp at low temperature
- Inverter start-up voltage
- MPPT minimum voltage
- MPPT maximum voltage
- Maximum DC input voltage

Output:

- Minimum permissible modules per string
- Recommended modules per string
- Maximum design modules per string
- Absolute maximum modules per string
- Status: PASS / WARNING / FAIL

---

## 6.3 Current Validation

For each string and MPPT calculate:

- String Imp
- String Isc
- Number of parallel strings
- Total Imp per MPPT
- Total Isc per MPPT
- Current per physical DC input
- Maximum input current utilisation
- Maximum short-circuit current utilisation

Display a red warning when:

- Short-circuit current exceeds the inverter limit
- The number of assigned strings exceeds connector quantity

# 7. Automatic String Grouping

Create a string grouping algorithm that proposes feasible combinations.

Input example:

- Total modules: 102
- Candidate string counts from roof plan:
  - 18 modules
  - 18 modules
  - 18 modules
  - 14 modules
  - 17 modules
  - 17 modules

The program should:

1. Validate every candidate string electrically.
2. Group strings with equal module quantities where possible.
3. Prefer strings from the same roof orientation and shading class.
4. Prefer adjacent physical groups where practical.
5. Minimise cable length.
6. Balance DC power between inverters.
7. Balance MPPT utilisation.
8. Avoid mixing unequal string lengths on one MPPT.
9. Avoid mixing significantly different orientations on one MPPT.
10. Avoid exceeding current and connector limits.
11. Identify unused MPPTs and unused inputs.
12. Calculate total assigned modules and unassigned modules.

Provide three design modes:

### Mode A — Conservative

- One string per MPPT where possible
- No unequal string lengths on the same MPPT
- No mixed orientations
- Maximum electrical margin

### Mode B — Balanced

- Permit two equal strings per MPPT
- Balance inverter loading
- Minimise unused MPPTs
- Maintain all manufacturer limits

### Mode C — Cost Optimised

- Minimise inverter quantity
- Minimise cable length
- Maximise reasonable MPPT utilisation
- Maintain all hard electrical constraints
- Show all engineering compromises

Never automatically approve a design containing unequal string lengths connected in parallel to the same MPPT.

The user may override a warning only by entering:

- Override reason
- Engineer name
- Date
- Supporting document

# 10. Cable Length Aggregation for PVsyst

The workbook must retain cable length per string.

For PVsyst export, calculate both:

## 10.1 Simple Average Loop Length

Average full circuit length by PVsyst sub-array.

## 10.2 Current-Weighted Equivalent Resistance

Calculate resistance for each string:

Ri = rho × Li / Ai

Calculate total loss:

Ploss_total = SUM(Ii² × Ri)

Calculate equivalent resistance representing the sub-array.

Do not use a simple arithmetic average when:

- Cable sizes differ
- Current differs
- String routes differ substantially
- Combiner topology differs

Output:

- Average one-way length
- Average loop length
- Equivalent cable resistance
- Nominal loss at STC
- Recommended PVsyst ohmic loss input
- Calculation method
- Warning when route lengths have high variation
